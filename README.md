# Лабораторная работа №3

**Цель:** 
* Разработать и протестировать пользовательский интерфейс приложения для учета расходов (Flet / Expense Tracker).
* Реализовать функционал добавления новых расходов с указанием суммы Amount и категории Category.
* Обеспечить динамическое обновление списка расходов и отображение общих затрат Total Expenses.
* Настроить сохранение и сериализацию данных в файл формата JSON expenses.json.
* Проверить работоспособность UI и корректность записи данных при добавлении новой записи.

**Github:** https://github.com/luiskin27/CheckList-test-Flet.git

---

### Описание проделанной работы

1. **Разработка UI и бизнес-логики:** 
   * Реализована форма New Expense с полями ввода суммы Amount, выбора категории из выпадающего списка Category и кнопкой сохранения Save.
   * Добавлена вычисляемая плашка Total Expenses, агрегирующая общую сумму всех внесенных расходов.
   * Реализован компонент списка расходов, отображающий иконку категории, её название и сумму в валюте som.

2. **Работа с данными и сохранение:**
   * Организовано хранение расходов в виде списка объектов в формате JSON в файле expenses.json.
   * Настроена автоматическая сериализация данных при нажатии кнопки Save.
